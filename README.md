## Featured project

### [Azure VM & Networking Lab](https://github.com/Cian-code/azure-vm-networking-lab)

A hands-on Azure lab where I deployed an Ubuntu Linux virtual machine, connected to it over SSH, and explored how Azure networking resources work together.

In this project, I:
- Created and inspected an Azure resource group, virtual network, and subnet.
- Connected to the Linux VM from Windows PowerShell using SSH key authentication.
- Used `ip address` and `ip route` to inspect interface addressing and routing.
- Tested outbound connectivity and DNS resolution using `ping`, `nslookup`, and `resolvectl`.
- Documented the architecture, test results, and Azure Portal screenshots.

[View the project documentation and screenshots →](https://github.com/Cian-code/azure-vm-networking-lab)
